# Como contribuir nesta atividade

Edite somente os arquivos indicados no material da aula. Preserve contratos, testes, workflow e Makefile.

Use commits pequenos, por exemplo:

```text
Completa primeiro objeto em C++
Espelha primeiro objeto em Python
Adiciona unidade aos sensores
```

Antes do push, execute o teste da etapa. No pull request, inclua:

- comando executado e resumo da saída;
- link da execução verde no GitHub Actions;
- explicação da equivalência conceitual entre C++ e Python;
- registro em `AI_LOG.md`, quando houver uso de agente.
