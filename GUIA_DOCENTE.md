# Guia docente — capítulo 03

## Preparação

1. Publique este diretório como `rafaelrezo/poo-primeiros-objetos`.
2. Preserve a branch `main` com o baseline compilável e testes intencionalmente vermelhos.
3. Cadastre a atividade no GitHub Classroom ou distribua por fork.
4. Valide a solução de referência em cópia privada antes de publicar.

## Condução

- Etapa 01: estudantes completam o exemplo explicado no Pages.
- Etapa 02: estudantes estendem o modelo com unidade e preservam a etapa 01.
- Use a primeira falha do CI como leitura formativa, não como punição.
- Peça que a dupla explique por que as sintaxes diferem, embora classe, objeto, atributo e método sejam conceitos comuns.

## Limites do autograding

Os testes são visíveis no fork e podem ser adulterados. Confirme histórico, diff e explicação no PR. Em avaliação, complemente com uma defesa oral curta ou um caso adicional não anunciado.
